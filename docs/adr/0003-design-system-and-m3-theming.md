# ADR-007: تنفيذ واعتماد نظام التصميم الموحد (Noor Al-Momin Design System) في تطبيق المؤمن

- **التاريخ**: 2026-10-18
- **الحالة**: معتمد وموثق ومنفذ بنجاح (Approved, Certified & Executed)
- **المشاركون**: مجلس القيادة والاستراتيجية العليا، CTO، Lead Architect، UI & Accessibility Engineer، Senior Implementer، QA Automation Engineer.

---

## 1. السياق وخلفية القرار (Context)
بناءً على طلب المستخدم عبر أمر `/company D:\برمجة\ططبيق المؤمن` لتنفيذ "الديزين سستم" (Design System) المحدد في الوثيقة الهندسية الرائدة `NOOR_ALMOMIN_DESIGN_SYSTEM.md`، اجتمع المجلس الهندسي والكوادر المتخصصة لتنفيذ نظام التصميم بدقة جراحية تضمن:
1. توفير كافة رموز التصميم (Tokens) القياسية: الأبعاد (Space)، الانحناءات (Radii)، الحركة والانتقالات (Motion).
2. بناء الأنماط الأربعة المعتمدة: الوضع الفاتح (Light)، وضع القراءة الهادئ (Sepia)، الوضع الداكن (Dark)، والوضع الليلي الفاخر (True Black OLED).
3. تطبيق معايير النفاذية العالمية WCAG AA (نسب تباين تفوق 4.5:1 للنصوص الأساسية وذهب العناوين).
4. الالتزام الصارم بخصوصية الخط القرآني (KFGQPC Uthmanic Script HAFS) ومضاعفات ارتفاع الأسطر وتصفير المسافات الأفقية (Zero Letter Spacing).
5. الحفاظ التام بنسبة 100% على التوافقية العكسية لكافة الشاشات والمكونات الموجودة دون كسر أي كود حالي.

---

## 2. القرارات الهندسية المعتمدة والتنفيذ (Decisions & Implementation)

1. **هندسة الرموز وتمديد الثيم (`tokens.dart`)**:
   - بناء سلم المسافات `Space` بقاعدة 4dp (`x1` حتى `x16`).
   - بناء مصفوفة الانحناءات `Radii` من `sm=8` حتى `full=999`.
   - بناء مصفوفة الحركات `Motion` مع منحنيات `easeOutCubic`.
   - بناء فئة `AlMominTokens` كتبعية `ThemeExtension<AlMominTokens>` مع دوال `copyWith` و `lerp` وامتداد `BuildContext.tokens`.

2. **الألوان والأنماط الأربعة (`app_colors.dart`)**:
   - إدراج لوحة العلامة التجارية المعتمدة: الزمردي 700 (`#0F5B45`)، الذهب 500 (`#B8893A`)، الذهب النصي 700 (`#7A5818`)، الورق العاجي (`#FBF8F1`)، والليل 900 (`#0F1714`).
   - اعتماد الأنماط الأربعة: `lightScheme`, `sepiaScheme`, `darkScheme`, `blackScheme`.
   - توفير لوحة التجويد الموحدة (`tajweedGhunnah`, `tajweedIkhfa`, `tajweedIdgham`, `tajweedIqlab`, `tajweedQalqalah`, `tajweedMadd`).
   - الحفاظ على أسماء الألوان القديمة كثوابت توافقية (Backward Compatibility Aliases).

3. **تايبوجرافيا القرآن الكريم (`quran_text.dart`)**:
   - ضبط عائلة الخط القرآني `KFGQPCHafs` مع درجات الأحجام الستة (XS إلى XXL من 22sp إلى 54sp).
   - فرض ارتفاع السطر المتناسق (2.0 إلى 2.2) وحظر المسافات الأفقية بين الحروف نهائياً.

4. **باني الثيم الكامل (`app_theme.dart`)**:
   - بناء كائن `ThemeData` وفق مواصفات Material 3 مع ضبط كامل للمكونات (الأزرار، البطاقات، قوائم التنقل، الأشرطة، الحقول، والحوارات).

5. **الزخارف الإسلامية والأرقام المشرقية (`ornaments.dart`)**:
   - توفير مكون علامة نهاية الآية `AyahEndMarker` مع تحويل تلقائي للأرقام الهندية/المشرقية (`ArabicIndicDigits`).
   - توفير نجمة السور الثمانية `SurahStarBadge` (ربع الحزب).
   - توفير الفاصل المزخرف الذهبي `IslamicSectionDivider`.

6. **جسر التوافق العكسي (`core/theme/app_theme.dart`)**:
   - إعادة تصدير كافة ملفات `app/theme/` ليظل أي استدعاء قديم يعمل دون تعديل.
